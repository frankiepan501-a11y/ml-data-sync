# 任务计划：美客多标准毛利月报生成器

## 目标

把财务已验收的 47 列美客多毛利表格式和 ERP 映射规则固化到 `ml-data-sync` 生产生成器，使未来月份在财务确认终稿后自动生成同格式飞书电子表格。

## 范围

- 采购成本继续只按 `ERP SKU` 关联，不改既有成本口径。
- 展示列自动填充：`中文名称 = ERP品名`，`分类 = 产品类型/三级分类/二级分类`。
- 映射优先级：产品信息维护表 ERP SKU 精确命中，其次产品采购成本台 ERP SKU，最后分销报价单 SKU。
- 任一 SKU 未命中、名称/分类为空、同优先级出现冲突时，整份月报停止生成并返回问题清单。
- 财务确认终稿后自动触发；重复回调必须幂等（重复触发不重复建表）。
- 新表移动到财务报表汇总知识库节点，生成 47 列主表 + 数据源 + 检查三个 Sheet。

## 不在本次范围

- 改动美客多营收、佣金、税费、广告费、采购成本、头程成本的既有计算口径。
- 修改已验收的 2026-07 表格。
- 批量补建历史月份。

## 测试接口（已在对话中说明）

1. 给定已结账月度 SKU 汇总与 ERP 产品资料，生成器返回完整的 ERP品名/分类以及 47 列表格数据。
2. 任一 SKU 未命中、字段为空或冲突时，生成器必须失败，且飞书创建动作不会发生。
3. 同一月份重复触发财务确认时，只返回已存在的报表，不重复创建。

## 验收标准

- 47 列标题、字段来源和计算公式与财务已确认的 2026-07 标准表一致。
- 现有 2026-07 数据 dry-run：57 行、44 个唯一 SKU、ERP 映射缺口 0、冲突 0。
- 映射失败场景测试能证明 fail-closed（失败即停止，不留半成品表）。
- 全量单元测试通过。
- 生产部署后，通过只读接口验证版本和 dry-run；不创建未来真实月份测试表。
- README/交接文档记录触发条件、字段口径、失败处理和回放方式。

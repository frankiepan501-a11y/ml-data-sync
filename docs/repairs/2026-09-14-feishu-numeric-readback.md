# 美客多毛利报表 V4：在线数值类型与回款公式修复

## 问题

2026-08 V3 在线飞书表中，`销售额(原币)` 和 `售价RMB` 看起来是数字，实际却是文本。飞书的 `SUM` 会忽略文本，因此 `回款(原币)` 和 `回款RMB` 只累计了负数费用，造成有销售的行大面积显示负回款。本地 Excel 会自动把这些字符串转为数字，所以旧的离线验收没有发现线上差异。

同一路径还有一个完整性缺口：数据源实际为 51 个业务字段加 `record_id`，共 52 列；旧代码只写入和回读 49 列，会漏掉尾部调整字段及追溯标识。

## P0 修复

- 在写入飞书数据源前，把所有财务数值字段转换为真正的有限数字；布尔值、非法数字、`NaN`、无穷值一律停止生成。
- 回款公式显式锚定销售额：`U=L+SUM(M:T)`，人民币回款为 `AI=Z+SUM(AA:AH)`，避免飞书再次因单元格类型异常漏加销售额。
- 数据源 Sheet 自动扩至 52 列，并对 52 列完整写入和回读。
- 完成标记写入前，使用飞书 `UnformattedValue` 回读线上实际计算值：所有公式列都必须是有限数字，关键列还必须满足两组回款恒等式。
- 报表版本升级为 V4。V4 的标题、生成键、完成标记和审批哈希均与 V3 分离；V3 只保留作历史证据，不覆盖、不删除。
- V3 的运营/财务确认不沿用到 V4。只有当前 V4 源数据哈希匹配时，状态页才允许显示财务、管理和提成可用。
- 旧 V3 已显示“财务已确认终稿”时，新 V4 卡仍可重新进入人审；但缺少版本哈希、哈希读取失败或哈希属于当前版本时继续拦截。卡片点击在写入前会重复检查，避免并发状态变化覆盖终稿。

## 验收要求

1. 离线全量测试和新增回归测试全部通过，且测试期间禁止外部 HTTP。
2. 生产发布后先执行 `commit=false` 预演，再生成 2026-08 V4。
3. 在线回读 67 行：`L/U/Z/AI` 均为真实数字，且逐行满足 `U=L+SUM(M:T)`、`AI=Z+SUM(AA:AH)`，允许的舍入误差不超过 0.02。
4. 对比 V3 与 V4 的 47 列：除数值类型修复及其下游公式结果外，不得出现业务口径变化。
5. 新 V4 必须重新走梁俊辉运营确认和林纯子财务确认；公司汇总链接只能在财务本人确认成功后更新，并保留旧链接回执。

## 回滚

若发布或在线回读失败，停止发卡并保持未放行。回滚代码使用发布提交的反向提交；V4 新文档可保留为失败证据，不删除 V3，不改公司汇总旧链接，不手工伪造审批状态。

## 2026-09-14 列扩容热修

### 问题与根因

梁俊辉点击 V4 运营确认卡后，模板“数据源”工作表需要从 49 列扩到 52 列。旧实现把“在末尾增加列”错误调用成 `insert_dimension_range`，并传入 `startIndex=49/endIndex=52`。该插入接口要求起止下标都在当前 49 列范围内，因此飞书返回 `90202 dimension endIndex wrong`。

原测试也断言了这组错误参数，形成“本地通过、线上失败”的假绿。错误发生在写审核数据、更新运营状态和发送财务卡之前，所以没有错误报表或重复财务卡流入下游。

### 改动

- `_ensure_columns` 改用官方末尾增加接口 `POST /dimension_range`。
- 增加数量按 `needed_columns - current` 计算；本次 49→52 明确为 `length=3`。
- 测试同时禁止再调用 `insert_dimension_range`，防止旧错误回归。
- 增加线上部署识别标记 `ml_feishu_column_append_v4_20260914=true`。
- 不改金额、公式、报表字段、审批口径或接收人；同根的行扩容潜在问题登记 P1，不混入本次最小 P0。

### 恢复与验收

- 未完成的 V4 复制表保留 `IN_PROGRESS` 证据并由生成台账原地复用，不删除、不另建第二份表。
- 原运营卡的失败动作允许重新领取；修复部署后由梁俊辉本人再次点击原卡，Codex 不代点。
- 本地定向测试：`69 passed, 21 subtests passed`。
- 本地全量测试：`222 passed, 43 subtests passed`。
- 线上必须先回读新健康标记，再确认原表出现 `COMPLETE`、状态变为“运营已确认”、审核链接回填且只发送一张财务卡。

### 剩余风险

`_ensure_rows` 仍沿用旧插入接口；当前报表 67 行、模板容量 200 行，不触发该路径。若未来报表超过 200 行，需另开 P1，用同样的末尾增加接口修正并先补 200→205 的回归测试。
